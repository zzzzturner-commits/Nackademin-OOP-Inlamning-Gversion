Test case Registrator.

Test case registrator är en enkel konsol applikation som ger en användare möjligheten att skapa testfall och sedan kunna se en lista av de testfall användaren skapat under sessionen.
Systemet startas från terminalen inuti visual studio code genom att skriva "python main.py" i terminalen.

Det finns även en .puml fil med i main branch som är ett klassdiagram som systemet byggdes efter.

Systemet är uppbyggt av 5st klasser som tillsammans får systemet att fungera.

Systemet är uppbyggt med single responsibility principle i åtanke.
